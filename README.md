# Security Write-Ups

Hands-on penetration testing write-ups by **Mohamed Sherif Eldamerdash**, junior penetration tester.

Each folder documents real lab work with screenshots of every step, from detection to a working exploit.

## Web application security

| Write-up | What it covers |
|---|---|
| [SQL Injection](web-sql-injection/) | 10 PortSwigger labs plus DVWA: WHERE clause data extraction, login bypass, database fingerprinting on Oracle and MySQL, schema enumeration, UNION attacks |
| [JWT Attacks](web-jwt-attacks/) | 6 labs: unverified and flawed signature verification, weak signing key cracking, jwk, jku and kid header injection |
| [Server-Side Template Injection](web-ssti/) | 5 labs: detection, building exploits from template engine documentation, unknown template languages, information disclosure |
| [OAuth Attacks](web-oauth/) | 3 labs: implicit flow authentication bypass, forced profile linking, account hijacking via redirect |
| [HTTP Request Smuggling](web-http-request-smuggling/) | CL.TE desynchronization exploitation and confirmation via differential responses |
