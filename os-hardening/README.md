# OS Hardening - NIST 800-53 Controls

Group project by **Mohamed Sherif Eldamerdash** and **Islam Hassan Mohamed** implementing operating system hardening controls from the NIST SP 800-53 framework, each documented with configuration evidence screenshots.

**Full report:** [OS-Hardening-G4-Report.pdf](OS-Hardening-G4-Report.pdf)

## Controls covered

- **AC-2 Account Management:** password policies enforcing length, complexity and rotation
- **AC-8 System Use Notification:** logon banners and usage notices
- **CM-11 User-Installed Software:** preventing non-root users from installing software
